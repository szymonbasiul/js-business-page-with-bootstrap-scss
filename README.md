## 1. Project Description

The ProGamers game developers' landing page is an interactive platform that allows developers to showcase their projects, present their offers and teams, highlight their achievements, and provide contact information. We use intuitive navigation, enabling users to easily access any section of the page. The website looks great on screens of all sizes.

The project was developed using **JavaScript**, **SCSS**, and **Bootstrap**, ensuring a modern and responsive user interface.

## 2. Technology Stack

### Frontend:

- **HTML5** – document structure
- **SCSS** – styling with variables and modularity
- **Bootstrap 5** – CSS framework for building responsive layouts
- **JavaScript (ES6+)** – website interactivity
